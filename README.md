# Drishti-AI
Drishti AI is an assistive technology designed for visually impaired people. Acting like a human eye with audio guidance, it helps users navigate safely, recognize obstacles, identify currency notes, and detect colors. With real-time voice support, Drishti AI empowers blind individuals to live independently and confidently.

Drishti AIDrishti AI is an innovative vision-intelligence solution designed to transform visual inputs into real-time, actionable data. Utilizing advanced neural networks, it specializes in high-precision object detection and scene interpretation. Designed with a focus on accessibility and automation, it acts as a digital "third eye" to enhance human-machine interaction.
